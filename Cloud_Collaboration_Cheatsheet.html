Topic 01 · Cloud Collaboration
📊 Collaborating on Spreadsheets
Airtable
airtable.com
Spreadsheet-Database Hybrid
Real-time co-editing with coloured cursors per user
Multiple views: Grid, Kanban, Calendar, Gallery, Form
Rich field types: attachments, checkboxes, dropdowns
Automations, @mentions, revision history
★ Unique: Multiple views (Grid, Kanban, Form in one)
Zoho Sheet
zoho.com/sheet
Full Cloud Spreadsheet
400+ functions including statistical, financial, text
Live co-editing with cell-level locking
Pivot tables, advanced charts, conditional formatting
Import/Export: .xlsx, .csv, .ods, .pdf
★ Unique: 400+ functions — closest to Excel in cloud
Apple Numbers
icloud.com/numbers
iCloud Spreadsheet
Real-time iCloud collaboration across all Apple devices
Beautiful pre-built templates for reports, budgets
Interactive charts that update automatically with data
Free with Apple ID · Browser access for non-Apple users
★ Unique: Free lifetime plan + beautiful Apple design
Topic 02 · Cloud Collaboration
🗄 Collaborating on Databases
Supabase
supabase.com
PostgreSQL Cloud DB
Browser Table Editor — insert, update rows collaboratively
Built-in Realtime subscriptions — changes push instantly
Row Level Security (RLS) — fine-grained access control
Auto-generated REST + GraphQL APIs from schema
★ Unique: Built-in Realtime subscriptions (live push)
PlanetScale
planetscale.com
MySQL Cloud DB
Git-like DB branching — dev/staging/production branches
Deploy Requests — team reviews schema changes before apply
Non-blocking schema changes — zero downtime deployments
Full Audit Log + query performance Insights
★ Unique: Git-like database branching (no other DB has this)
MongoDB Atlas
mongodb.com/atlas
NoSQL Document DB
Atlas Data Explorer — browse & edit JSON documents in browser
Visual Aggregation Pipeline Builder
Atlas Charts — live dashboards from DB data, shared with team
Flexible JSON documents — no fixed schema required
★ Unique: Atlas Charts — visual dashboards from DB data

Topic 04 · Cloud Collaboration
☁ Storing & Sharing Files and Online Content
Dropbox
dropbox.com
Sync-First Storage
Smart Sync — cloud files appear on desktop, no disk space
Share links with password + expiry date controls
Version history 30–180 days · Dropbox Transfer (100GB)
Dropbox Paper — collaborative doc editor built-in
★ Unique: Dropbox Transfer — send 100GB via one link
Box
box.com
Enterprise Content
6 permission levels per user (Owner → Viewer)
Full Audit Activity Feed — every action logged
Box Sign — legally binding e-signatures in browser
Classification labels: Confidential / Internal / Public
★ Unique: Full audit trail + e-signatures (Box Sign)
pCloud
pcloud.com
Privacy-First Storage
Lifetime plan — pay once, use 500GB/2TB forever
pCloud Crypto — zero-knowledge client-side encryption
Share links with password, expiry, download permission
Built-in media player — play audio/video from cloud
★ Unique: Lifetime plan + pCloud Crypto (zero-knowledge)

Workplace Calendar

RSVP attendee tracking — accept/decline per person
CalDAV sync — connects to any cloud calendar provider
★ Unique: Natural Language Parsing + weather overlay

asana.com
Full Project Management
4 views: List, Board (Kanban), Timeline (Gantt), Calendar

Milestones, Workload view, Rules & Automation
Portfolio — track multiple projects in one dashboard
★ Unique: Task dependencies + Timeline (Gantt) view
Trello
trello.com
Visual Kanban Board
Kanban cards — drag between To Do → In Progress → Done
Cards with checklists, due dates, labels, attachments
Butler Automation — auto-move cards, send alerts
Power-Ups — add Calendar view, GitHub, Slack integration
★ Unique: Simplest visual Kanban — drag-and-drop workflow
Todoist
todoist.com
Priority-Driven Tasks
P1–P4 colour flag system (Red/Orange/Blue/Grey)
Natural language: "Send report every Friday at 9am P1"
Karma system — rewards task completion with points
Recurring tasks, custom filters, labels across projects
★ Unique: P1–P4 flags + Karma gamification system
